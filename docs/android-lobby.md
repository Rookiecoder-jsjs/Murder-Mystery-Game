# 安卓首页与剧本库

2026-10-06。应用版本 `1.0.0-preview.5` / versionCode 18；公开 APK、校验值和对应源码见 [发布说明](https://github.com/Rookiecoder-jsjs/Murder-Mystery-Game/releases/tag/v1.0.0-android-preview.5)。

## 页面结构

| 入口 | 内容 |
| --- | --- |
| 首页 `/` | 最近一局、两个已安装的推荐故事 |
| 剧本库 `/library` | 所有官方故事、搜索、全部／可开局／有更新筛选 |
| 我的 `/my` | 存档与复盘、个人剧本、生成、模型任务、模型设置、下载记录、离线内容包安装 |
| 案件详情 `/library/:storyId` | 完整封面与简介、人数和难度、版本说明、内容管理、模式选择及开局／下载／更新 |

底部导航只在三个主入口显示。次级页面显示返回按钮；系统返回键先处理弹层、抽屉和可见键盘，再返回对应父页面。故事详情优先返回进入它的首页、官方列表或个人列表；直接打开详情时返回剧本库。游戏页保留原有回首页行为。

## 列表与状态

- 条目采用小封面、标题、单行简介、角色数／难度／时长和状态；完整介绍与管理操作进入详情查看。
- 官方列表按故事 ID 保持稳定顺序，每次展开 20 本；搜索同时覆盖安装版与目录新版的公开标题、简介。
- 查询、筛选、展开数量和滚动位置在当前应用进程内保留，进入详情或游戏后返回仍可恢复；冷启动会重新读取本地资料，不承诺恢复上次的筛选状态。
- “我的剧本”也保留当前进程内的搜索、展开数量和位置，进入个人故事详情后返回不会清空查询。
- 在“有更新”范围内完成更新的故事暂时保留原条目，并显示“更新完成”；切换筛选或搜索后重新计算。
- 已安装故事使用本地版本的介绍；新版信息单独展示，不用远端元数据替换实际开局内容。不兼容的新版提示升级应用，旧版仍可开局。
- 大封面和正文独立滚动，详情底部模式与主要操作始终可见。安全区继续由现有原生根布局处理，键盘打开时隐藏主导航。

## 数据与任务

`frontend/src/pages/mobile/` 只负责安卓页面。`useStoryLibrary` 共享官方目录状态与任务轮询，`useLocalLobby` 读取本地设置摘要、存档、未完成模型任务和个人故事；重复读取合并，后台暂停周期轮询。目录检查沿用每日检查策略，只获取目录，不自动下载故事。

内容操作继续使用现有 `libraryApi` 和原生签名校验、不可变版本、原子安装与冻结存档链路。内容下载和模型任务在“我的”中分开查看；界面只报告真实下载字节或任务阶段，大小未知时使用不定进度。

成品开局仍调用本地 `/games/load`，不重新审稿或生图；后续 AI 对话使用手机已有密钥和网络。设置入口使用原生加密凭据界面，页面只读取是否配置成功的摘要。APK 保留三个基础本，不包含开发环境密钥或手机数据。

真机验证用 APK 大小26,587,726 bytes，SHA-256 `9d269e865082ee2052377ee131d7a1e178d60b5b44c3891569137c8e8c1bce17`；递归检查1,318个条目、3个基础故事和18张配图，凭据检查通过。发布时从固定源码提交重建，APK内源码链接与附件源码一致，发布产物的校验值以Release附件为准。本地产物为 `frontend/android/app/build/outputs/apk/debug/app-debug.apk`，不加入Git。

## 2026-10-06 修复版

修复版本为 `1.0.0-preview.5` / versionCode 18；上述 preview.4 公开附件保留，供历史版本核对。

- 新开局、续局、重置都会使旧视图的异步回写失效；阶段、线索、投票结果、错误、加载状态和任务提示均不能串到另一局。即使离开后重新进入同一游戏 ID，也拒绝上次视图的迟到结果。
- 继续中断任务时使用手机最新模型设置。原问题、已完成发言与冻结角色上下文保留；调用缓存按模型服务地址和完整请求隔离，旧缓存只在原服务地址下兼容读取。
- 复盘读取失败显示错误及“重试读取复盘”；返回前台时可以再次读取，无需退出游戏。
- 个人列表查询及展开数量移到大厅共享状态，详情返回时配合原有滚动恢复。

回归覆盖延迟投票后切换存档、同 ID 再进入、其他动作与错误迟到、重置、纠正模型后重启继续、保留已完成角色及跨服务缓存隔离。前端 8 个测试文件、移动引擎 8 个测试、原生内容校验 8 个测试、ESLint、Web 和 APK 构建均通过；所有模型回归使用模拟服务，不使用真实密钥。

Redmi Android 16 真机已同签名覆盖升级到 versionCode 18，验证通过：

- 个人列表搜索进入详情后返回仍保留；45 条临时公开测试数据按 20／40 展开，详情返回保留查询、展开数量和滚动位置。临时数据仅在测试桥中提供，未写入手机或 APK。
- 注入一次复盘读取失败后停止转圈并显示重试入口；点击重试在原页面成功读取复盘。
- 将旧局投票结果延迟到另一存档打开之后返回，新局仍停留在序幕，没有显示旧局真相；该投票由测试桥模拟，未发送到游戏引擎。
- 升级前后加密配置、游戏数据库与下载注册表校验值一致。完成界面回归后仍有 23 个存档（8 个复盘、12 个序幕、3 个讨论）、6 本已安装官方故事和 4 本个人故事，密钥与下载注册表校验值保持一致；测试桥已还原，无未完成模型或下载任务，无横向溢出。

APK 递归检查 1,318 个条目、3 个基础故事和 18 张配图，凭据检查通过。发布产物由固定源码提交重建，校验值及对应源码以 Release 附件为准。验证覆盖故障恢复与界面流程，不代替整局真实模型实玩。
