## 当前许可范围

除另有许可说明的第三方材料外，本仓库维护者提供的项目源码及其修改采用 **GNU Affero General Public License version 3 only（SPDX：`AGPL-3.0-only`）**。根目录 [LICENSE](../LICENSE) 是 GNU 官方完整英文条款；本文用于说明，不增加、删减或替代许可证条件。“only” 表示指定第 3 版，不自动授权使用后续版本。

源码范围包括后端、Web 客户端、安卓本地引擎与原生桥接、小程序客户端和构建脚本。内置故事及配图的授权同时参照各内容包的来源与许可元数据；未另行标注许可的本项目内容随仓库许可发布。第三方依赖、工具及其代码或资源依各自许可证授权。

AGPL 允许收费、商用、修改与再分发。新贡献按当前项目许可提供；引入第三方材料时须保留其有效的版权、归属和许可信息。

## 哪些情况需要提供源码

| 使用方式 | 对应源码要求 |
| --- | --- |
| 本地自用，不分发，也不让网络用户使用修改版 | 不因这种使用要求公开私人修改 |
| 分发本项目或其修改版源码 | 按许可证保留许可、适用声明及修改说明，提供受许可覆盖的源码 |
| 分发本项目或其修改版 APK、其他二进制 | 按第 6 条向接收者提供对应源码及所要求的信息；发布可下载二进制时，可在同一下载处提供对应源码的等同获取方式 |
| 让用户通过网络与修改版交互 | 按第 13 条在修改版中显著向所有这些用户提供免费获取该版本对应源码的机会 |

“对应源码”应是实际交付或部署版本的完整受许可覆盖源码，包括重建、安装、运行及修改所需的适用脚本与说明，不能只给补丁、过期分支或没有包含下游修改的上游链接。第 6 条适用时还须提供安装信息，具体边界以完整许可证为准。

提供源码面向许可证规定的接收者或网络用户；不要求一切私人代码无条件面向全世界公开，也不自动将无关的独立系统纳入范围。API key、令牌、真实用户存档和日志不应放入源码包；用示例配置与操作说明替代。

本次改为 AGPL 从**包含此次许可变更的首个提交及后续版本**开始适用，不改写旧提交或撤销已经授予的 Apache 权利。

此前已按 Apache License 2.0 发布的代码版本仍可按其原有许可使用，包括：

- 提交 `58a6f8e0cdf1f32656b32864b229156e54dfdb21` 及此前已按 Apache 2.0 发布的版本。
- 安卓预览 Release `v1.0.0-android-preview.1` 和 `v1.0.0-android-preview.2`，及其当时发布的附件。

[licenses/Apache-2.0.txt](../licenses/Apache-2.0.txt) 保留完整 Apache 2.0 条款，用于上述历史版本及适用的第三方材料；它不是当前项目的默认许可，也不是当前版本的双重许可选项。旧版授权已经覆盖的代码仍保留既有权利，仅改许可证不能让这些旧代码的使用者必须改用 AGPL。

## 后续发布与部署

发布新的 AGPL 版本时，在 Release 页面给出该 APK/二进制对应的固定源码标签或提交及源码下载入口，连同 `LICENSE`、构建脚本、依赖清单与所需构建说明交付。源码地址应指向实际发布版本，而不是会持续变化的默认分支。README 中已发布的旧 APK 链接仍指向 Apache 版本，不能标成新 AGPL 版本。

网络部署修改版时，在用户可见的页面或客户端中提供显著的“对应源码”入口，并确保它指向当前部署版本的完整源码。下游部署者应发布自己的修改；仅保留本项目的 GitHub 链接不能替代该义务。

第三方依赖保留各自许可证和所要求的声明；Gradle 包装器等文件中的 Apache 声明继续保留。本次项目许可变更不替代对具体发行包中第三方材料的许可核对。
